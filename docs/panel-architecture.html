System Architecture

US IN Updated 2026-09-03 01:39 UTC
How this page's own data actually gets here, end to end — for tracing a number back to its source rather than taking it on faith.

1. Where the numbers come from

Prices (United States)Financial Modeling Prep (FMP)
Prices (India)Yahoo Finance (yfinance)
Sector / industry classificationTradingView's public screener — both markets
Breadth universeS&P 1500 constituents (iShares IVV/IJH/IJR holdings CSVs)

2. Pipeline order (src/main.py, one country at a time)

  1. Pull TradingView classification (sector/industry tags, and India's universe)
  2. Build the breadth universe (S&P 1500 for US; top-1000 by cap for India)
  3. Update the rolling price cache — new tickers get full history; existing ones get the last 7 days re-checked (not just today — see the reliability note below)
  4. Backfill index history (OHLC + EMA10/20/50 + volume where available) — fetched directly per index, independent of the breadth universe
  5. Backfill breadth internals (advance/decline, new highs/lows, % up/down) from the price cache
  6. Backfill sector and industry performance/rank
  7. Compute the Market Environment read (trend/participation/internals)
  8. Compute relative-strength ratings
  9. Run TMLE (leader-scoring engine) — US only, since it needs FMP fundamentals with no India coverage on this plan
  10. Render every page in docs/ from what was just written

3. Update schedule

United StatesGitHub Action daily-us.yml — runs after United States's own market close, independently of the other country
Session cutoff21:30 UTC — today's bar is excluded entirely until the wall clock clears this, so a live/forming session is never mistaken for a finished one
Self-healingEvery run recomputes the full trailing 252-day window and upserts by date — a day that failed to price on one run fills itself in on the next successful one, automatically

4. Storage model

data/us/*.jsonlPermanent accumulating history, one row per session, git-tracked in main. This IS the chart history.
docs/panel-*.htmlGenerated pages, one per panel, rebuilt fresh every run and git-tracked (so the last good render always survives a bad run).
docs/tickers/Per-ticker price files (chart depth back to 2020) — deliberately not git-tracked in main (thousands of files rewritten daily would bloat history for nothing); lives only on the gh-pages branch and this hub's local sync.

5. Known data caveats

  • nasdaq (NASDAQ Composite) — own volume from Financial Modeling Prep (FMP)
  • sp500 (S&P 500) — own volume from Financial Modeling Prep (FMP)
  • russell2000 (Russell 2000) — proxy: IWM
  • Russell 2000's own volume from FMP is byte-identical to the S&P 500's every day — not real Russell volume, just a mirrored composite figure — which is why it uses IWM (the Russell 2000 ETF) as a proxy instead.

6. Reliability

FMP's real-time quote endpoint previously went dark for entire runs on several separate days, pricing under 1% of tickers while reporting success — breadth/sector/industry correctly refused to count those as sessions and fell behind, while index history (fetched differently) kept advancing, which is what caused different panels to show different "as of" dates with nothing explaining why. Today's close is now fetched via the same historical-EOD endpoint used everywhere else, and a run aborts loudly (committing nothing) if fewer than 50% of tickers come back priced, rather than silently accepting a near-empty session.
