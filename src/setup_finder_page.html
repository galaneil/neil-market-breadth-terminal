Setup finder

Big up-moves from the stored price history (2020 to now), each with a likely entry: the first breakout out of a base before the run, or the start of the move if there was none. Set the filters, save them as a named set, then go down the list: click a ticker to see the chart, change the entry or the setup type if you disagree, and keep or skip. Your edits are saved as you make them. Stocks that are no longer listed are not in the price files, so results lean toward survivors.
